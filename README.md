# 🌍 World Explorer

A responsive country explorer web application built using **HTML, CSS, Bootstrap, JavaScript**, and the **REST Countries API**. Users can browse all countries and search/filter them by **Country Name, Country Code, Continent, and Capital City** with a modern premium UI.

---

## 🚀 Features

* View all countries with flags and basic details
* Search countries by:

  * Country Name
  * Country Code
  * Capital City
* Filter countries by:

  * Continent / Region
* Real-time filtering without page reload
* Responsive premium glassmorphism UI
* Loading spinner while fetching API data
* No results handling message
* Clear filters button for better usability

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6)
* REST Countries API
